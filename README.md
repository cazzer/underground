# underground

A live, low-fi architectural wireframe view of the NYC subway: zoom toward a station and the camera tilts from top-down to isometric.
Static site (Vite + React + react-three-fiber) deployed to GitHub Pages. Currently runs on hand-made sample data.
`npm install && npm run dev`, then open the URL Vite prints (path `/underground/`). Try `?theme=blueprint|drafting|terminal`.
See `AGENTS.md` for conventions.
